# Roadmap

Heddle plans warp ends, yarn length, and a reed for a handloom cloth. This is the first of six updates. About 38 hours of later work stay after those six.

## Still in the six updates

### Threading (update 2)

Write a straight draw and a point draw across the shafts in the project.

### Tie-up and treadling (update 3)

Add a plain-weave and a 2/2 twill tie-up, and print the lift for each pick.

### Take-up and shrinkage (update 4)

Turn the on-loom width and length into a finished size.

### Drawdown (update 5)

Draw a few repeats of the cloth as an SVG.

### Compare (update 6)

Compare two plans by ends, yards, and finished width.

## After the sixth update

These stay after the six updates. They are about 38 hours.

### Warp stripes (4 hours)

Repeat a color sequence across the warp and count the ends of each color.

### Color order (3 hours)

Print the color of each end from the right selvedge, in groups of the threading repeat.

### Floating selvedge (3 hours)

Add one extra end at each side that is not in the threading, and include it in the yardage.

### Bobbin count (3 hours)

Estimate how many weft bobbins a woven length needs from a chosen yards-per-bobbin.

### Weft yardage (4 hours)

Take picks per inch and report the weft yarn in yards and pounds.

### Temple note (2 hours)

Warn when the reed width is wider than a chosen temple.

### Sectional beam (4 hours)

Split the warp into sections of a chosen inch width and report ends per section.

### Mixed warp (4 hours)

Allow more than one yarn in the warp and total the pounds of each.

### Draft file (3 hours)

Write the threading, tie-up, and treadling to a JSON file another tool can draw.

### Repeat check (4 hours)

Fail the plan when the end count is not a whole number of threading repeats, plus the selvedges.

### Waste presets (4 hours)

Offer front-to-back and back-to-front loom waste amounts, and show which one the plan used.

The threading draft is the next piece. The plan counts ends and shafts, and it does not yet say which shaft each end uses.
